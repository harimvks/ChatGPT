# Pilot Ready Boundary

The repository-side pilot infrastructure is complete enough for local execution. This marker does not represent completed model trials.

## Ready

- frozen experiment plan;
- logical model bindings;
- task-selection policy;
- Gateway-compatible rollout boundary;
- artifact normalization;
- isolated candidate sandbox;
- external validation;
- trajectory persistence;
- experiment runner;
- report layer;
- local execution runbook.

## Not yet evidenced

- actual 12-cell model execution;
- measured small-model pass rate;
- measured Qwen3.6-27B pass rate under this exact pilot;
- scaffold effect;
- reproducible failure clusters.

The first model-performance claims must come from the local runtime evidence bundle, not from repository state or model-card benchmarks.
